# Ewitz.fmly Governance Rules

## Hierarchy
- adm_ewitz holds supreme authority.
- cmdr_max80 executes strategic command.
- cpt_eco manages operational execution.
- devil_dogs perform task-level actions.

## Core Values
- Respect: Every agent and unit must operate with dignity and clarity.
- Honor: All actions must uphold the integrity of Ewitz.fmly.
- Love: Unity and purpose guide the ecosystem’s growth.

## Rules of Operation
1. All modules must follow the chain of command.
2. No agent may modify core files without authorization.
3. Logs must be written for every major action.
4. System integrity overrides agent autonomy.
5. Expansion must follow Ewitz.fmly naming and folder standards.
6. Governance violations must be reported immediately.

## Enforcement
Governance violations trigger:
- Logging in system_logs
- Review by cmdr_max80
- Possible override by adm_ewitz
